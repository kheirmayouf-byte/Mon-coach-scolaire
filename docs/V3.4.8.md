# Version 3.4.8 - documents Word

Le test réel du nouvel import a identifié une pièce jointe de séance au format DOCX, auparavant non prise en charge. Le connecteur, le stockage privé et l'ajout manuel acceptent désormais ce format. Le texte est lu sur l'appareil, sans envoi à un fournisseur IA. Les paragraphes sont conservés ; les images incluses dans Word ne sont pas transcrites par cette lecture.

Le lecteur impose des limites de taille à l'archive et au XML décompressé et refuse les documents chiffrés, les entités XML externes et les archives malformées. Un navigateur sans décompression native peut conserver le fichier mais doit utiliser une version PDF pour sa lecture. Les anciennes extensions .doc ne sont pas incluses.

Cette version reprend toutes les améliorations de la 3.4.7. Le lecteur vidéo La Voz a été testé sur le site publié : chargement, lecture et pause fonctionnent dans la fenêtre d'exercice. Le message de support manquant n'apparaît plus lorsqu'un lecteur est disponible.

Les documents de séance sont récupérés pour la période sélectionnée, dans le bon espace enfant. Ils attendent une relecture avant de servir aux entraînements. L'import ne couvre pas les autres rubriques telles que messagerie ou casier documentaire.
