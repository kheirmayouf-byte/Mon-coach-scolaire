MON COACH SCOLAIRE — VERSION ORDINATEUR 3.4.3
Version de test pour Windows 10/11, 64 bits

1. Extrais TOUT le fichier ZIP dans un dossier de ton ordinateur.
2. Dans ce dossier, ouvre « Mon Coach Scolaire.exe ».
3. Depuis le bouton en haut « Parents & connexion », connecte ton compte parent habituel
   pour retrouver les devoirs et les documents du foyer.
4. Dans « Mon abonnement ChatGPT », clique « Continuer avec ChatGPT ».
   Ton navigateur habituel s’ouvre sur OpenAI. Choisis ton compte Plus
   et autorise explicitement l’utilisation de ton abonnement.
5. Reviens dans l’application puis clique « Tester la connexion ».
   Une réponse complète confirme l’accès pour ton compte.

Aucune clé API à créer. Aucun achat de crédits. Aucun relais payant
si ta limite d’abonnement est atteinte. « Gérer mon utilisation »
ouvre le suivi ChatGPT. L’éligibilité reste à confirmer par le test.

AVANT LES DEMANDES CONCERNANT UN ENFANT
Dans Mon compte, vérifie la fiche pédagogique de chaque
enfant et coche « J’ai vérifié ces consignes pour cet enfant ».
Les projets Prof Noor et Prof Bettina ne sont pas automatiquement lus.
Colle leurs consignes utiles dans la fiche du bon enfant.
Pour les quiz, ajoute le cours dans Documents, vérifie son texte,
puis valide « J’ai vérifié ce texte avec l’original ».
Sélectionne l’enfant ou ouvre son devoir avant de poser ta question.

Cette version répond aux questions écrites et propose des quiz QCM
depuis les supports vérifiés. Les PDF contenant du texte sont lus
sur l’appareil. Pour un scan ou une photo, complète le texte dans
Documents. Le bouton Micro utilise le moteur de reconnaissance vocale
française de Windows. Autorise le microphone et installe la langue
française si nécessaire. Le mode conversation alterne dictée et lecture ;
il ne s’agit pas du mode vocal temps réel de ChatGPT. La lecture dépend
des voix disponibles sur Windows.

Les accès ChatGPT restent sur cet ordinateur, chiffrés par Windows.
Seuls les contenus nécessaires à ta demande sont transmis à OpenAI.
Le compte parent et le compte ChatGPT sont deux connexions distinctes.
La connexion ChatGPT est conservée sur cet ordinateur. Pour la retirer,
utilise explicitement Déconnecter ChatGPT dans Mon compte.
Le site web peut désormais utiliser ce moteur sur le même ordinateur,
à condition de garder cette application ouverte et de valider le
rattachement dans Mon compte sur le site. L’iPhone et l’iPad ne peuvent
pas joindre ce relais local.

Cette version de test n’a pas de signature d’éditeur Windows.
Si Windows empêche l’ouverture, relève le message affiché : ne
désactive pas les protections de ton ordinateur pour l’exécuter.
La connexion réelle avec ton compte et le lancement sous Windows
restent à valider sur ton ordinateur.

Code source : https://github.com/kheirmayouf-byte/Mon-coach-scolaire
Usage familial non commercial. Notices dans resources/app.asar,
build/siwc-notices ; licences Electron dans le dossier principal.

NOUVEAUTÉS 3.4
Mon compte regroupe les connexions et disponibilités. ÉcoleDirecte est
conservé chiffré dans le compte parent après une première reconnexion.
Les vérifications de sécurité du fournisseur peuvent être redemandées.
Les documents non vérifiés affichent directement leur éditeur.
Une session ouvre une fenêtre dans l’application : pause, chrono masquable,
fermeture avec reprise, réponses sauvegardées et annulation sans bilan.
Les devoirs dont la date est dépassée passent automatiquement à Fait.
Emploi du temps affiche les cours importés et les pastilles de devoirs.
Le chat reste accessible grâce au bouton Ton coach en bas à droite.

CONNEXION DE LA VERSION EN LIGNE 3.4.3
Ferme une ancienne version Windows avant d’ouvrir celle-ci.
Garde l’application ouverte. Sur le site, connecte le compte parent
puis choisis Mon compte > Mon IA > Continuer avec ChatGPT.
Autorise le rattachement dans la fenêtre Windows et l’accès local du
navigateur s’il le demande. Les demandes IA se font ensuite dans le site.
Le bouton Retirer le lien avec la version en ligne supprime ce rattachement.

SÉCURITÉ DU RELAIS 3.4.3
Le site envoie au relais une autorisation signée par Supabase, valable
pour une seule demande et pendant 45 secondes. Le jeton du compte parent
n’est pas transmis au relais. Les accès ChatGPT restent dans le coffre local.
